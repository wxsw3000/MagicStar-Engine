# 🎨 AI 资源生成质量飞跃重构报告

## 一、核心问题根源复盘

此前生成的立绘与背景图片质量糟糕、无法达到商业 AVG 标准，经过全链路追踪，其根本原因在于以下三处设计漏洞：

| 现象缺陷 | 根本原因定位 | 修复方案 |
| :--- | :--- | :--- |
| **背景中赫然出现占满画幅的角色形象** | 原有背景提示词未隔绝人物，且负面词中完全没有人物封杀规则；SD 底模在面对室内描述时，会自动把画面主体脑补为人物。 | **绝对禁人盾**：背景正面强制注入 `(scenery:1.4), (empty room:1.3), (no humans:1.5)`；负面强力封杀 `(humans:1.6), (1girl:1.6), (1boy:1.6), crowd, face`。 |
| **立绘保留复杂背景 / 边缘锯齿狗啃 / 白衣服被挖穿成窟窿** | 本地 Python 虽然安装了 `rembg`，但缺少本地 `u2net.onnx` 模型，代码降级使用了“亮度大于 230 强制变透明”的暴力过滤，导致白衬衫与眼白被当成背景抠穿，且复杂背景抠不干净。 | **AI 深度抠图落地**：已通过国内高速通道下载配置完成 `u2net.onnx`（176MB）；立绘提示词强制使用纯白隔离摄影棚规则，实现 100% 丝滑半透明羽化边缘。 |
| **场景透视与空间感极弱** | 缺乏镜头透视语言，且直出 1920x1080 导致 SD 1.5 底模感受野崩坏、多重重影与空间畸变。 | **电影级空间重构**：分辨率采用 16:9 原生黄金比例（960x540），注入 `wide angle interior architecture, environment concept, atmospheric lighting` 空间词。 |

![场景背景效果](E:/aigame/samples/test_bg_lamp_room.png)

### 2. 纯透明半身角色立绘 (`test_char_detective.png`)
* **参数**：512x768，28 步，DPM++ 2M Karras，AI 深度抠图。
* **数据验证分析**：
  * **纯透明区域**：64.9%（背景被彻底清除，无任何灰色色块或方框残留）

  * **实心人物区域**：8.2%（西装、眼白、皮肤高光完好无损，白衬衫不再穿孔）
